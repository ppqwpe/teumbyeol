# 틈별: 몽환 / 엉뚱 / 귀여움

## 참고한 공식 자료
- [Eastward](https://eastwardgame.com/): 생활감 있는 장소, 이상한 이웃과 따뜻한 유머를 참고.
- [Hyper Light Drifter](https://store.steampowered.com/app/257850/Hyper_Light_Drifter/): 넓은 공간과 색의 대비를 참고.
- [UNDERTALE](https://undertale.com/about/): 짧은 캐릭터 대사와 의외의 비폭력적 반응을 참고.

위 항목은 틈별을 위한 디자인 해석입니다. 타 게임의 이미지, 음악, 캐릭터, 코드는 가져오지 않았습니다.

## 이번 적용
- 확정된 모찌 캐릭터의 낮은 검은 눈과 비율을 유지.
- 보라/청록 원경, 부드러운 픽셀 대기, 버터색 작은 광원.
- 이끼숲과 바람들 새 배경 2종. 나머지 지역은 기존 배경을 유지하고 작은 공통 입자와 발견 사물을 적용.
- 8개 지역의 엉뚱한 사물, 발견 후 브라우저에 남는 꿈 조각.
- 친구별 짧은 반응. 바람 지역의 낮은 중력 점프.
- 도감 성운과 사각 UI, 캐릭터가 겹치지 않는 중심 배치.
- reduced motion 설정을 존중.

배경은 내장 이미지 생성 도구로 새로 제작했습니다.
